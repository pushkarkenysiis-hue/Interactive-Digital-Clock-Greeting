# Interactive Digital Clock Greeting
Description: 
<br>
A web application that displays a live digital clock along with a personalized greeting based on the current time of day. The greeting changes dynamically (e.g., "Good Morning", "Good Afternoon", "Good Evening") to create an interactive and engaging user experience.
<br>
<ul>
  Features:
  <li>Real-time digital clock display</li>
  <li>Dynamic greeting messages based on time of day</li>
  <li>Responsive design for desktop and mobile</li>
  <li>Simple, clean, and beginner-friendly codebase</li>
</ul>
<br>
<ul>
  Usage:
  <li>Open the webpage in your browser.</li>
  <li>The clock will automatically update every second.</li>
  <li>Greeting messages will change depending on the current time.</li>
</ul>
<br>
Customization:
<br>
You can edit the greeting logic in script.js to add more personalized messages (e.g., "Happy Weekend!", "Good Night").
<br>
Style the clock and greeting in style.css to match your preferred theme.
